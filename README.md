# IndyGL

a typescript library for building 3D modeling applications

![screenshot](img/screenshot.png)

this library is going to be the new foundation for [makehuman.js](https://github.com/markandre13/makehuman.js)

things working so far:

* programmatically add wavefront obj meshes to the scene
* fly mode
* select objects
* move, rotate, scale objects either in viewport or via sidepanel
